# SatStockvel (SatsStokvel) — Bitcoin Community Savings

> Save in sats. Payout in stacks. Ubuntu through Bitcoin.

[Open the live demo](https://geeradebe.github.io/SatStockvel/)

## Origin & Vision

Tefo Given Radebe originated the name **SatsStokvel** in 2021, with a vision of bringing South African Ubuntu stokvel principles to Bitcoin Dollar-Cost Averaging (BCDCA / DCA). SatStockvel brings the community savings model into a Bitcoin context, combining shared contributions, transparent tracking, and rotational payouts.

## Key Features

- **Dual ZAR & sats tracking** — View contributions and pool values in South African rand and satoshis.
- **Rotational payout schedule** — Track the planned payout order across the savings cycle.
- **Real-time pool summary** — See contributions, cycle totals, member count, and the next payout at a glance.
- **Flexible cycle settings** — Configure the cycle length to suit the group.
